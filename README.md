# Exercício de exemplo: soma

Modelo de exercício dos [Bossini Codelabs](https://professorbossini.dev/codelabs/) corrigido pelos testes do GitHub Actions.

1. Clique em **Use this template** → **Create a new repository** e deixe o repositório **público**.
2. Implemente a função `soma(a, b)` em `soma.py`, que devolve a soma de `a` e `b`.
3. Faça commit e push. Os testes rodam sozinhos na aba **Actions**.
4. Cole o endereço do seu repositório no exercício, no site, e clique em **Verificar testes**.

Não altere a pasta `tests/` nem o arquivo `.github/workflows/testes.yml`: o site confere se eles estão iguais aos do modelo.
